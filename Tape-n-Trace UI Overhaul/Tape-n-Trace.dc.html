Why a DFA needs a total δHopcroft 2e §2.2.1

Proof, written from the round

Suppose, for contradiction, that L = { 0ⁿ1ⁿ } is regular with pumping length p = 4. Take w = 0⁴1⁴ ∈ L, so that |w| ≥ p. By the pumping lemma there is a decomposition w = xyz with |xy| ≤ p, y ≠ ε and xyⁱz ∈ L for every i ≥ 0. Since |xy| ≤ 4, the block y consists only of 0s. Pumping with i = 2 yields {{ pumped }}, which has strictly more 0s than 1s and therefore lies outside L. This contradicts the lemma, so L is not regular. □
